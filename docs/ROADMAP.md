# 路线图

> 说明：本文件是最初的里程碑规划，里面的编号（0.0.2 / 0.1.0 / 0.2.0 / 1.0）与后来实际发布的版本号已经不再一一对应。
> 实际发布到哪一版、每版做了什么，以 [CHANGELOG](../CHANGELOG.md) 为准（当前 0.1.0 = HUD 毛玻璃交互框重构）。
> 下面未打勾的条目统一视为「后续计划」，编号顺延，不再当版本号用。

## 0.0.2 可用性补丁（1-2 周）
- [ ] 云端 provider 联调并固化（火山 flash 识别 + 百炼 qwen-flash 润色）
- [ ] 托盘图标与右键菜单（暂停 / 设置 / 退出）
- [ ] 双击常开模式、热键可配置
- [ ] 麦克风预缓冲（按下前 300ms），避免吃掉第一个音节
- [ ] 失败提示与「已复制到剪贴板」降级路径
- 出口：真实语音连续 20 句不出错，P95 不超过 1.5s

## 0.1.0 经验闭环（3-4 周）
- [ ] 流式 ASR（WebSocket 增量）→ 边说边出预览
- [ ] 历史记录（SQLite + DPAPI 加密）与保留期
- [ ] 用户改错自动学习（把 learn_from_edit 接到投递后校验）
- [ ] UIA 焦点上下文：密码框拦截、按应用排除、选区替换
- [ ] 图形设置页（模型 / 热键 / 词库 / 隐私）
- 出口：20 个常用应用的兼容性矩阵通过

## 0.2.0 性能与稳健（4 周）
- [ ] 引擎独立进程 + 命名管道 IPC（崩溃隔离）
- [ ] 本地模型（sherpa-onnx 识别 / llama.cpp 润色）作为离线模式
- [ ] 渐进式修正：先出原文，润色回来后焦点未变则原地替换
- [ ] 本地指标（延迟直方图、错误分类）与一键导出诊断包
- 出口：崩溃率低于 0.5%，断网可用

## 1.0 可分发（4-6 周）
- [ ] 自动更新（MSIX / WinSparkle）+ 灰度 + kill switch
- [ ] 代码签名（EV）与 SmartScreen 通过
- [ ] TSF 文本服务：内联合成、任意应用可用（真正的输入法级体验）
- [ ] 许可 / 试用 / 配额（若使用云端代理网关）
- 出口：安装包小白可用，更新可回滚
